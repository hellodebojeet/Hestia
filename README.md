# Hestia

- `apps/web` — Next.js social client
- `apps/api` — stateless REST engine
- `apps/realtime` — WebSocket gateway (presence, chat, live reactions)
- `apps/worker` — queues (feed fan-out, stories cleanup, transcoding)
- `packages/cache` — Redis timeline/counter/presence
- `packages/storage` — S3/R2 presigned uploads
